## Learning outcomes
By the end of this lecture, learners can:
- Define custom tools and connect them to a LangChain AgentExecutor using the ReAct pattern
- build a multi-step agent that selects and calls tools based on input
- construct a working mini-agent build — either a CSV Analyst or FAQ Helpdesk — and control its execution safely

## Topics to cover
- LangChain Tool, create_tool, AgentExecutor, ReAct agent, initialize_agent, tool selection logic, multi-step action loops, max_iterations, handle_parsing_errors, mini-build: CSV Analyst or FAQ Helpdesk agent
