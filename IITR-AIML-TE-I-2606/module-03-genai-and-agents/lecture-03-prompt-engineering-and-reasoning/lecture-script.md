## Learning outcomes
By the end of this lecture, learners can:
- Design effective zero-shot and few-shot prompts for specific tasks using role prompting
- apply chain-of-thought reasoning to improve multi-step problem solving
- evaluate and iteratively refine prompts using a defined test set and failure analysis

## Topics to cover
- Role prompting, zero-shot prompting, few-shot prompting, chain-of-thought prompting, prompt evaluation with small test sets, iterative prompt refinement, prompt failure analysis
