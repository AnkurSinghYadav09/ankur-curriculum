## Learning outcomes
By the end of this lecture, learners can:
- Design a multi-step agent workflow using LangGraph StateGraph with defined nodes and transitions
- implement conditional edges to handle branching logic and retry handling across agent steps
- compare LangGraph orchestration with LangChain AgentExecutor and justify when to use each

## Topics to cover
- LangGraph StateGraph, nodes, edges, conditional edges, add_node, add_edge, compile(), state management across nodes, retry handling, multi-step agent flow design, LangGraph vs AgentExecutor, when to use each
