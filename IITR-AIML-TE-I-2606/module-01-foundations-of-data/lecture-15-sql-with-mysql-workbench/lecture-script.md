## Learning outcomes
By the end of this lecture, learners can:
- Write SQL queries to filter, sort and group data in MySQL Workbench
- join two or more tables using INNER, LEFT and RIGHT joins
- choose the correct join type for a given multi-table scenario

## Topics to cover
- MySQL Workbench setup, SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, GROUP BY, HAVING, INNER JOIN, LEFT JOIN, RIGHT JOIN, aliases
