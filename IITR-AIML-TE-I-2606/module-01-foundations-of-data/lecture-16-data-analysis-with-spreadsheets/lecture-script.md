## Learning outcomes
By the end of this lecture, learners can:
- Use VLOOKUP and XLOOKUP to retrieve values across sheets
- build pivot tables to summarize and slice data
- apply COUNTIF and conditional formatting to surface quick data insights

## Topics to cover
- VLOOKUP, XLOOKUP, pivot tables, filters, sorting, conditional formatting, basic formulas (SUM, AVERAGE, COUNTIF), named ranges
