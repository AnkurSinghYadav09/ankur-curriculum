## Learning outcomes
By the end of this lecture, learners can:
- Read and write files safely using context managers
- parse and generate JSON data
- make API calls using requests, handle responses and apply ethical usage of API keys and rate limits

## Topics to cover
- File I/O, open(), context managers, JSON structure, json.loads/dumps, requests library, GET/POST, status codes, API keys, rate limiting, ethics, ToS
