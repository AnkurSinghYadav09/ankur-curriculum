## Learning outcomes
By the end of this lecture, learners can:
- Build an end-to-end RAG pipeline connecting a ChromaDB retriever to an LLM via LangChain
- inject retrieved context into prompts to ground LLM responses in source documents
- compare grounded vs ungrounded responses to analyze and reduce hallucination

## Topics to cover
- LangChain RetrievalQA, create_retrieval_chain, combine_documents_chain, connecting retriever to LLM, prompt with context injection, grounded document Q&A, hallucination reduction, grounded vs ungrounded response comparison
