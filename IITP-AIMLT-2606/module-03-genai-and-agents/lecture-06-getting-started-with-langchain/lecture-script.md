## Learning outcomes
By the end of this lecture, learners can:
- Set up LangChain with OpenRouter as the LLM backend and explain why frameworks like LangChain exist
- build prompt templates using PromptTemplate and ChatPromptTemplate
- chain multiple LLM calls using LLMChain and SequentialChain

## Topics to cover
- LangChain setup, ChatOpenAI with OpenRouter base URL, PromptTemplate, ChatPromptTemplate, LLMChain, SequentialChain, why LangChain over raw API calls
