## Learning outcomes
By the end of this lecture, learners can:
- Chunk documents using RecursiveCharacterTextSplitter with appropriate size and overlap
- index document chunks into both ChromaDB and FAISS and compare their trade-offs
- retrieve relevant chunks using similarity search and MMR retrieval

## Topics to cover
- LangChain RecursiveCharacterTextSplitter, chunk size and overlap strategies, ChromaDB setup and indexing, FAISS setup and indexing, similarity search, MMR retrieval, VectorStoreRetriever, ChromaDB vs FAISS comparison
