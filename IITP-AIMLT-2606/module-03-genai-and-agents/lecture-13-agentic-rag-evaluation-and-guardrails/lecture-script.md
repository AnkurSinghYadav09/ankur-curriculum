## Learning outcomes
By the end of this lecture, learners can:
- Wrap a ChromaDB retriever as a LangChain tool and integrate it into an AgentExecutor for agentic RAG
- evaluate RAG pipeline quality using RAGAS metrics — answer correctness, context recall and faithfulness
- implement guardrails and explain responsible AI principles around hallucination, privacy and reliability

## Topics to cover
- LangChain retriever as tool, create_retrieval_tool, agentic RAG pattern, RAGAS framework, answer correctness, context recall, faithfulness score, hallucination detection, guardrails design, privacy considerations, reliability principles, responsible AI framework
