## Learning outcomes
By the end of this lecture, learners can:
- Recall and explain how LLMs generate text using tokens and context windows
- interpret the effect of temperature and top-p on output variability
- compare LLMs with traditional ML models in terms of how they learn and predict

## Topics to cover
- LLM architecture intuition, tokenization, context windows, temperature, top-p, cost and latency basics, LLM vs traditional ML
