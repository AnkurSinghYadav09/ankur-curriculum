## Learning outcomes
By the end of this lecture, learners can:
- Set up OpenRouter and make raw LLM API calls using the requests library without any framework
- structure system, user and assistant messages correctly
- parse API responses and handle errors and rate limits responsibly

## Topics to cover
- OpenRouter setup, API keys with python-dotenv, requests to OpenRouter endpoint, free model selection, message structure (system, user, assistant), response parsing, error handling, rate limiting
