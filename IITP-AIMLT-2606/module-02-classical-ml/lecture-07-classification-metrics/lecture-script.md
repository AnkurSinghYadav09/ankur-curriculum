## Learning outcomes
By the end of this lecture, learners can:
- Compute and interpret all classification metrics using sklearn.metrics
- analyze the confusion matrix to explain false positives and false negatives
- evaluate the precision-recall tradeoff and select the right metric for a given business scenario

## Topics to cover
- confusion_matrix, accuracy_score, precision_score, recall_score, f1_score, roc_curve, roc_auc_score from sklearn.metrics, threshold tuning, precision-recall tradeoff
