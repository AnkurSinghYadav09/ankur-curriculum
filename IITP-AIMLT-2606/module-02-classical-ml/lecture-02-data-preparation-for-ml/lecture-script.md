## Learning outcomes
By the end of this lecture, learners can:
- Build an end-to-end preprocessing pipeline using sklearn Pipeline and ColumnTransformer
- apply correct encoding and scaling strategies for different feature types
- identify and prevent data leakage within a preprocessing workflow

## Topics to cover
