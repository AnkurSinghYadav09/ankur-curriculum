## Learning objectives
By the end of this session, learners can:
- Explain why a language model needs retrieval to answer from private or recent documents
- Encode a list of text documents into embedding vectors using a hosted model
- Compute the cosine similarity between two embedding vectors
- Implement brute-force semantic search that ranks a document set against a query
- Chunk a document into fixed-size passages with overlap between neighbours
- Write embedded documents into a vector store together with their ids and metadata
