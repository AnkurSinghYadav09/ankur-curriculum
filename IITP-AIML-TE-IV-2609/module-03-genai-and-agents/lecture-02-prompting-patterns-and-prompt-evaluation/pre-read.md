## Topics covered
- Builds on 13.1: raw calls give inconsistent answers, so shape them with prompting patterns and measure the fix
- role and system prompts
- few-shot examples
- chain-of-thought (CoT)
- a tiny prompt-eval set with expected outputs
- pass rate as a quality baseline (reused in 15.1 and 16.2)

## Learning objectives
By the end of this session, learners can:
- Write a system prompt that fixes the assistant's role, scope and constraints
- Apply role prompting to set the vocabulary and depth of an answer
- Construct a few-shot prompt with worked input-output examples
- Write a chain-of-thought prompt that requests reasoning before the final answer
- Construct a fixed eval set of inputs and expected outputs for a stated LLM task
- Compute the pass rate of an eval suite and record it as a quality baseline
