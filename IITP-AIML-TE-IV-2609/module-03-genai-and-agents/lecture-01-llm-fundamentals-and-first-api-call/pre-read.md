## Learning objectives
By the end of this session, learners can:
- Describe how a tokenizer splits text into subword tokens
- Explain what a context window limits and what counts against it
- Configure temperature, top-p and max tokens for a stated task
- Call a hosted LLM API, extracting the generated text from the response envelope
- Compute the cost of a single API call from input and output token prices
- Select a model for a stated task, justifying by capability, cost and latency
