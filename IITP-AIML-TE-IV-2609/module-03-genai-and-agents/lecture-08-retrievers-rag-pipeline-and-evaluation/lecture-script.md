## Learning outcomes
By the end of this lecture, learners can:
- Query a vector store for the top-k nearest neighbours of a query vector
- Configure a retriever's top-k and score threshold for a stated context budget
- Write a prompt that instructs the model to answer only from supplied reference text
- Build a working retrieval-augmented pipeline over a provided document corpus
- Compute retrieval recall at k for a RAG pipeline against a labelled question set
- Compute answer correctness for RAG outputs against reference answers on a labelled question set

## Topics to cover
- Builds on 15.2: stored chunks only help if the right ones come back and the answer is checked
- LangChain intro: installing it and wrapping the 15.2 Chroma store as a retriever
- retrievers: top-k from the vector store
- grounded prompts that answer only from context
- an end-to-end RAG pipeline
- RAG eval: answer correctness & context recall
