## Topics covered
- Module 3 wrap-up, building on 16.1: the agent from 14.2 and the retriever from 16.1 become one system, and its steps are made explicit as a graph
- a retriever the agent calls only when a question needs the corpus
- an agent graph of nodes and edges
- a conditional route that sends a run down a different branch
- a retry and fallback path when a tool call fails
- then designing an agent for a stated workflow, naming its tools, memory and stopping rule

## Learning objectives
By the end of this session, learners can:
- Implement a retriever tool that an agent calls when a question needs the document corpus
- Configure the tool set and role assigned to an agent in a framework
- Construct an agent graph with nodes and edges in LangGraph
- Implement a conditional route that sends a run down a different branch
- Implement a retry and fallback path for a tool call that fails
- Design an agent for a stated workflow naming its tools, memory and stopping rule
