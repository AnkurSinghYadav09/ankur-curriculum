## Learning outcomes
By the end of this lecture, learners can:
- Construct a NumPy array from a Python list or nested list
- Explain why a vectorised array expression runs faster than an equivalent element loop
- Parse a CSV file into a DataFrame using read_csv with a stated separator and index column
- Retrieve rows and columns by label using .loc
- Retrieve rows and columns by position using .iloc
- Filter rows of a DataFrame using a boolean mask on one column

## Topics to cover
- Builds on 4.2: SQL answered these questions inside the database, but the data has to come back into Python to be modelled later, and looping over thousands of order rows is slow and clumsy
- NumPy arrays
- vectorised operations vs loops
- pandas Series vs DataFrame
- loading the orders CSV with read_csv
- inspecting head, shape and dtypes
- indexing with loc and iloc
- filtering rows with a boolean mask, the pandas answer to 3.2's WHERE
