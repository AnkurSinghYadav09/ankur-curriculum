## Topics covered
- Builds on 4.1: the join types are known, so now write the query a business actually asks for
- one question answered by a single statement that joins, filters and aggregates at once, pulling 3.2's WHERE and GROUP BY together with 4.1's join
- joining a third table through a shared key
- the classic trap of a LEFT JOIN silently reduced to an inner join by a WHERE filter
- then the same filter-and-summarise questions answered where business teams already work, at intro level only: filtering and sorting a table without breaking row alignment, and a pivot table aggregating a measure by category, the spreadsheet echo of 3.2's GROUP BY

## Learning objectives
By the end of this session, learners can:
- Write a single query combining a join, a filter and an aggregate to answer a business question
- Write a query joining three tables through a shared key
- Debug a LEFT JOIN silently reduced to an inner join by a WHERE filter
- Filter and sort a table on multiple criteria without breaking row alignment
- Build a pivot table that aggregates a measure by one or more categories
