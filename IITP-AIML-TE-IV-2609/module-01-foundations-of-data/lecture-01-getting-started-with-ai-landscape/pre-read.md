## Topics covered
- Course starting point: where AI, ML and GenAI fit, then a working place to write code
- AI vs ML vs GenAI landscape
- command line (CLI) basics: cd, ls, paths
- environments: a virtual environment and pip installs from the terminal
- VS Code with the project's Python interpreter
- Google Colab and Jupyter notebooks with a one-line print demo
- notebooks discipline: code vs markdown cells, restart-and-run-all before sharing
- secrets are handled in the pre-recorded Git & GitHub pre-work

## Learning objectives
By the end of this session, learners can:
- Compare AI, machine learning and generative AI by what each term covers
- Apply cd and ls to reach a target directory and list its contents
- Configure a virtual environment for a project and activate it
- Configure VS Code to run a project file with the project's interpreter selected
- Write and run code in a notebook cell, separating code cells from markdown cells
