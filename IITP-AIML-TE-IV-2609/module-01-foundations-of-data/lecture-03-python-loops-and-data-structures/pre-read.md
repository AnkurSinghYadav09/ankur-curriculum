## Learning objectives
By the end of this session, learners can:
- State the ordering, mutability and duplicate rules of lists, tuples, sets and dictionaries
- Write a list and access its elements using positive and negative indexing
- Build a dictionary of key-value pairs, retrieving a value by its key
- Write a for loop that iterates over a sequence
- Write a while loop that terminates on a stated condition
- Extract a single field from each record in a list of dictionaries
