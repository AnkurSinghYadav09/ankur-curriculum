## Learning outcomes
By the end of this lecture, learners can:
- Write a script that stores values in named variables following Python naming conventions
- Classify a value as int, float, str or bool
- Convert a value between string, integer and float types
- Construct a boolean expression using comparison and logical operators
- Implement branching logic for a stated business rule using if/elif/else
- Predict which branch of a conditional executes for a given input

## Topics to cover
- Builds on 1.1: first Python code written in the course notebook, working on a single food-delivery order
- variables and data types (int, float, str, bool)
- converting between types
- arithmetic, comparison and logical operators
- if/elif/else decisions (Python flow, part 1)
