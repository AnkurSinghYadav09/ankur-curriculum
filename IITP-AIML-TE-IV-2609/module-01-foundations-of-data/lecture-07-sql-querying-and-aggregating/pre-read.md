## Topics covered
- Builds on 3.1: reading the orders file row by row answers one question slowly, so load the same orders and restaurants data into a SQLite database and ask the database instead
- SQL lite: tables, rows and schema
- what a relational database stores and how a schema defines it
- SELECT with named columns
- WHERE with comparison operators
- ORDER BY with ASC/DESC and a tie-break column
- GROUP BY with COUNT/SUM/AVG
- joins follow in 4.1

## Learning objectives
By the end of this session, learners can:
- Describe how a relational database stores data as tables, rows and a defined schema
- Write a SELECT query returning named columns from a single table
- Filter rows using comparison operators in a WHERE clause
- Write a query that sorts results on multiple columns with mixed ASC and DESC
- Aggregate rows per category using GROUP BY
