## Topics covered
- Builds on 2.2: the functions from 2.2 need real data, and the orders really live in CSV and JSON files on disk
- reading files with a with-block and why the file closes itself
- CSV files with DictReader, keyed by column name
- reading JSON files into dictionaries and lists
- try/except so one bad row or a missing file does not crash the script

## Learning objectives
By the end of this session, learners can:
- Write a script that reads a text file into a string using a with-block
- Parse a CSV into dictionaries keyed by column name using DictReader
- Parse a JSON file from disk into Python dictionaries and lists
- Catch FileNotFoundError and return a stated fallback instead of crashing
- Catch a JSON decoding error raised by a malformed file
