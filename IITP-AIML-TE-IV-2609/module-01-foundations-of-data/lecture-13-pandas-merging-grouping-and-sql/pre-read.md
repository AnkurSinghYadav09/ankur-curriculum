## Topics covered
- Builds on 5.2: the orders table is clean, but restaurant details still sit in a separate file and the questions are the ones 3.2 and 4.1 answered in SQL
- joins/merge of orders with restaurants on a key
- inner vs left joins in pandas
- groupby aggregation
- groupby.agg with several functions
- closing the loop on SQL <-> pandas: WHERE is a boolean mask, GROUP BY is groupby, JOIN is merge, so a query from 3.2, 4.1 or 4.2 can be rewritten either way

## Learning objectives
By the end of this session, learners can:
- Join two DataFrames on a shared key using merge
- Compare inner, left, right and outer joins by which rows survive each
- Aggregate one column by a grouping key using groupby
- Aggregate several columns with different functions using groupby.agg
- Convert a SQL query that filters, groups or joins into equivalent pandas code
