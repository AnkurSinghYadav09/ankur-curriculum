## Learning outcomes
By the end of this lecture, learners can:
- Write a function that takes arguments and returns a computed value
- Explain why a variable defined inside a function is not visible outside it
- Refactor a repeated block of code into a reusable function
- Call a function using positional and keyword arguments
- Write a function with default parameter values
- Apply string methods to normalise casing and whitespace in a text value

## Topics to cover
- Builds on 2.1: the same order-processing loops keep repeating, so wrap them once and call them by name
- defining functions with parameters and return values
- calling a function with positional and keyword arguments
- default parameter values
- variable scope, and why a name inside a function is invisible outside it
- refactoring a repeated block of order-processing code into a reusable function
- string methods to normalise casing and whitespace before that data is cleaned in 5.2
