## Learning outcomes
By the end of this lecture, learners can:
- Convert a working notebook into a runnable Python script
- Refactor an ad-hoc notebook cleaning sequence into a rerunnable ordered pipeline
- Configure a .env file and load credentials from it at run time
- Catch a failed request so one bad response does not stop the whole data pull
- Build a Streamlit page that filters a cleaned dataset and displays its exploratory charts
- Write a requirements.txt pinning the versions a project depends on

## Topics to cover
- Module 1 wrap-up: every step so far joined into one small app
- ingest (7.2 API or CSV) -> clean (5.2) -> EDA (7.1) -> share on GitHub (pre-recorded pre-work)
- turning notebook steps into a rerunnable script
- installing Streamlit and pinning packages in requirements.txt
- loading the API key from a .env file
- handling a failed API pull with try/except from 3.1
- optional Streamlit page with a filter and charts
- closes Module 1: we have explained what happened, next we predict what will happen
