- optional Streamlit page with a filter and charts

## Learning objectives
By the end of this session, learners can:
- Convert a working notebook into a runnable Python script
- Refactor an ad-hoc notebook cleaning sequence into a rerunnable ordered pipeline
- Configure a .env file and load credentials from it at run time
- Catch a failed request so one bad response does not stop the whole data pull
- Build a Streamlit page that filters a cleaned dataset and displays its exploratory charts
- Write a requirements.txt pinning the versions a project depends on
