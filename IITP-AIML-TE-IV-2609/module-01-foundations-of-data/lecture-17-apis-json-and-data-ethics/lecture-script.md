## Learning outcomes
By the end of this lecture, learners can:
- Call a public REST endpoint from Python and inspect the response
- Construct a request with query parameters that filter the data returned
- Interpret an HTTP status code to state whether the client or the server must change
- Transform a list of nested JSON records into flat rows ready for analysis
- Identify the usage limits, attribution rules and data-reuse terms in an API's terms of service
- Validate a proposed use of data against the purpose it was collected for

## Topics to cover
- Builds on 7.1: so far the data came from static files, but fresh data (ratings, weather) comes from APIs, and APIs come with rules
- how a web API call works
- GET requests with the requests library, and POST with a JSON body (used again in 15.1)
- query parameters
- status codes
- turning nested JSON into rows
- basic ethics/ToS: terms of service, usage limits, using data only for its stated purpose
