## Topics covered
- Builds on 6.2: charts made one at a time miss things, so apply a repeatable EDA checklist to the orders data
- what one row represents (grain)
- profiling every column: type, range, missing values
- distributions
- outliers with the IQR rule (quartiles and the 1.5 x IQR fences)
- correlations with a target (reading -1 to 1)
- writing a reusable EDA checklist

## Learning objectives
By the end of this session, learners can:
- Describe the grain of a dataset, stating what a single row represents
- Profile a tabular dataset reporting per-column type, range, cardinality and summary statistics
- Interpret a histogram to describe a variable's distribution shape and modality
- Compute outlier boundaries for a numeric column using the interquartile-range rule
- Interpret a correlation matrix to shortlist candidate drivers of a target variable
- Design a reusable exploratory checklist for a new tabular dataset
