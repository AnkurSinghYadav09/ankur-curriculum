## Learning outcomes
By the end of this lecture, learners can:
- Train a logistic regression model for a binary target
- Construct a confusion matrix from predicted and actual labels
- Compute precision, recall and F1 from a confusion matrix
- Compute an ROC curve and its AUC from predicted probabilities
- Convert predicted probabilities into class labels at a chosen threshold
- Explain why accuracy misleads on a heavily imbalanced dataset

- threshold tuning
