## Topics covered
- Builds on 8.2: the baseline needs clean, numeric inputs
- data prep: missing values (why values go missing: at random or systematically, then drop or impute for modelling)
- duplicates
- categorical encoding (one-hot)
- scaling (standardisation)
- leakage guard: fit preprocessing on the training split only
- chaining steps in a scikit-learn Pipeline

## Learning objectives
By the end of this session, learners can:
- Select between dropping and imputing missing values, justifying by missingness share and mechanism
- Remove duplicate records keyed on a subset of columns, keeping a stated record
- Encode a nominal categorical column using one-hot encoding
- Apply standardisation to numeric features
- Explain how fitting a scaler before splitting leaks test information into training
- Build a scikit-learn Pipeline chaining preprocessing steps to an estimator
