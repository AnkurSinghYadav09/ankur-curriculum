## Learning outcomes
By the end of this lecture, learners can:
- Describe a time series as trend, seasonality, cycle and noise components
- Explain why time series data breaks the independence assumption behind a random train/test split
- Split a time series into train and test sets preserving time order
- Construct lag and rolling-window features from a time-indexed column
- Build a seasonal-naive baseline forecast
- Evaluate a forecast against a seasonal-naive baseline on held-out periods

## Topics to cover
- Builds on 12.1 and the 9.2 date features: daily order counts are ordered in time, so a random split breaks
- Time Series (lite)
- trend, seasonality, cycle and noise
- time-ordered train/test split
- lag and rolling-window features
- seasonal-naive baseline forecast
- a lag-feature linear regression forecast (reusing 10.1) checked against that baseline
- closes Module 2: models predict numbers and labels, next LLMs read, write and act
