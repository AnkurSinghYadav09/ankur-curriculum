## Learning outcomes
By the end of this lecture, learners can:
- Train a multiple linear regression model on several numeric features
- Compare overfitting and underfitting by their training and validation error signatures
- Compute MAE and RMSE for a set of regression predictions
- Interpret an R-squared value against a mean-predicting baseline
- Analyze a residual plot for non-linearity and non-constant variance
- Compare Ridge and Lasso by their effect on coefficient magnitudes

## Topics to cover
- Builds on 9.2: first real model on the engineered features, predicting delivery time in minutes
- Linear Regression
- reading coefficients
- metrics MAE/RMSE/R2 (R-squared) compared with the 8.2 baseline
- quick error analysis with residual plots
- overfitting vs underfitting
- regularization: Ridge and Lasso as the fix for overfitting
