## Topics covered
- Opens Module 2 on the same orders data: from describing what happened to predicting what happens next
- ML workflow & habits
- problem framing: target, features, unit of analysis
- regression vs classification targets
- the scikit-learn fit/transform/predict interface, shown with one transformer (SimpleImputer) and one estimator
- train/validation/test split with a fixed seed
- baselines a model must beat

## Learning objectives
By the end of this session, learners can:
- Describe the stages of an ML workflow from problem framing to deployment
- Convert a business question into an ML task naming target, features and unit of analysis
- Classify a supervised problem as regression or classification from its target variable
- Apply the fit, predict and transform interface of a scikit-learn estimator
- Construct a three-way train, validation and test split for model selection
- Construct a baseline predictor that a trained model must beat
