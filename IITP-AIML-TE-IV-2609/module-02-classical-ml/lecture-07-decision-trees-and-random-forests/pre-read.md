## Learning objectives
By the end of this session, learners can:
- Train a decision tree classifier on a labelled tabular dataset
- Interpret a plotted decision tree as a set of if-then rules
- Configure depth and leaf-size constraints to limit the complexity of a decision tree
- Diagnose overfitting from the gap between training and validation scores
- Train a random forest classifier on a tabular dataset
- Extract ranked feature importances from a fitted tree ensemble
