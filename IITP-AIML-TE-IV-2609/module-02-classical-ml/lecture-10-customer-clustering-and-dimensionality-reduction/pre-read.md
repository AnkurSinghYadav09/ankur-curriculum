## Topics covered
- Builds on 11.2: not every question has a label to predict, e.g. what kinds of customers do we have?
- Unsupervised Learning vs supervised, with a one-line look at reinforcement learning
- k-means clustering on the 9.2 per-customer features, scaled as in 9.1
- choosing k with the elbow
- profiling customer segments
- PCA to reduce and visualise features

## Learning objectives
By the end of this session, learners can:
- Classify a described problem as supervised, unsupervised or reinforcement learning
- Cluster a scaled numeric dataset into k groups using k-means
- Select k where the marginal drop in inertia falls below a stated fraction of the previous drop
- Interpret cluster centroids as segment profiles described in business terms
- Apply PCA to reduce a feature set to a stated number of components
- Select the number of principal components, justifying by cumulative explained variance
